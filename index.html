Connection checklist

Before the live connection works:

  • Deploy the FastAPI backend to a stable HTTPS host.
  • Backend must expose POST /api/generate.
  • Request format: {"prompt":"...","system_instruction":"..."}.
  • Response format: {"html":"...complete HTML..."}.
  • Enable CORS for https://warglitch451-ops.github.io.
  • Use server-side secrets, rate limits and usage controls.
CORS is not authentication and does not prevent all API abuse. Never ship your master API key to the browser.

How this builder connects

The Website Builder sends your prompt to the saved endpoint. The backend must call your loaded build_nameforge_website function and return its HTML in the html field. The current frontend cannot wake up a stopped Colab runtime.
